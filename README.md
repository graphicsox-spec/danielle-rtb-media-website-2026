
# Raise The Bar Media (RTB Media) — Ultra-Luxury Agency Redesign

A cutting-edge, high-conversion boutique PR and marketing agency web platform for **Raise The Bar Media (7083 Hollywood Blvd, Los Angeles)**.

## 🚀 Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS v4 + Obsidian & Champagne Gold Custom Luxury Design System
- **Icons**: Lucide React
- **Audio Engine**: Web Audio API Synthesized Micro-Haptics
- **Effects**: Glassmorphism, Kinetic Marquees, Dynamic PR ROI Calculator, Confetti VIP Proposals

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
